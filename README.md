UndergroundBiomesConstructs [Reworked]

UndergroundBiomesConstructs [Reworked] brings back the classic underground biome experience, reimagined and updated for Minecraft 1.21.1.

This mod is based on the original 1.7.10 version by Zeno410.
Original version here: UndergroundBiomesContructs

About the Project

This is a fun project and also my first biome mod. The goal is to make underground exploration more varied and interesting by adding diverse new biomes.

As it is a hobby project, bugs or issues may still be present

Compatibility

The mod should work alongside other biome mods. Tested with Biomes O' Plenty

Further testing with other mods may follow.

Version & Future Plans

Currently planned for Minecraft 1.21.1

No backports to older versions are planned

The focus is entirely on the current version.
